# 🐍 Sapola | Snake Game

A high-octane, neon-themed recreation of the classic Snake arcade game. Built with a focus on smooth performance, responsive design, and modern web aesthetics.

---

### 🕹️ Live Gameplay
* **Grow:** Consume food to increase your length and climb the leaderboard.
* **Survival:** Avoid colliding with the boundaries or your own body.
* **Dynamic UI:** Real-time score tracking, high-score persistence, and a game timer.

### 🚀 Technical Features
* **Vanilla Stack:** Built using pure **HTML5**, **CSS3**, and **ES6+ JavaScript**.
* **Mobile Optimized:** Features a custom-built **Neon D-Pad** and responsive grid scaling for play on any device.
* **Persistent Data:** Uses `localStorage` to save your highest score across sessions.
* **Visuals:** Modern "Cyberpunk" aesthetic using CSS variables, blur filters, and neon glow effects.
